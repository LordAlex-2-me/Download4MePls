# Download4MePls

A personal remote-file fetcher. Give it a URL, it downloads the file server-side, and you pick it up whenever you're ready.

---

## Features

* Fetch any publicly accessible URL
* Supports:

  * Basic Authentication
  * Bearer Tokens
  * Cookies
  * Custom HTTP Headers
* Live progress tracking
* Retry failed downloads
* One-click download of fetched files
* Clean dark-themed UI

* Each download job is stored using a unique UUID.
* Job state is currently stored in memory and resets on server restart unless replaced with a database.
* The app does **not** include authentication by default.
